# Crawler RIT de "Los Ramírez"

**Autores:** Elías Ramírez Hernández, Ignacio Ramírez Hernández.

Versión muy inmadura del proyecto del crawler para el curso de Recuperación de la Información Textual.

## ¿Qué es esto?
La idea de este crawler es iterar sobre un conjunto de links semilla inicial, y obtener muchos más links semilla, los cuales se guardarán en diferentes archivos enumerados `URLs0.txt`, `URLs1.txt`, `URLs2.txt`, etc., hasta llegar a `n` iteraciones. La idea es que desde el .txt inicial se extraigan los links de las páginas y se guarden en `URLs0.txt`, y que de ese archivo se extraigan los links de las páginas y se guarden en `URLs1.txt`... Hasta llegar a un número de iteraciones con el que estemos felices.
